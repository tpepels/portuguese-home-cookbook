# Recipe images

Add one JPG per recipe using the exact path from `data/recipes.js`.

Until a file exists, the HTML automatically shows a designed placeholder with the recipe title.

Recommended source image:

- portrait orientation
- at least 1600 × 2260 px
- food fills most of the frame
- natural, domestic Portuguese setting
- no text baked into the image

The page uses `object-fit: cover`, so keep important food details away from the extreme edges.
